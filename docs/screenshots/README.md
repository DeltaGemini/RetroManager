# Screenshots

Pictures of RetroManager in use, for the main README.

They show a **demo library of made-up games**: every game name, description,
studio and picture in them was invented, and the pictures were drawn by
`tools/make_demo_library.py` from shapes. `tools/take_screenshots.py` takes
them again from that library. No real game, box art or logo appears in them.

The consoles' names (on the system tiles, which RetroManager draws itself) are
there only to say which system is which; they belong to their makers.

RetroManager comes with no games, BIOS files or game media of any kind: it
organises a library its user already has.
